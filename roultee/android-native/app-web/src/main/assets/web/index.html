How to place bets

1. Choose a chip — tap the chip stack on the right, then pick a value.

2. Place bets — tap any number or outside bet on the board. Tap again to add another chip.

3. Undo / Double — use Undo to remove the last chip, or ×2 to double all open bets.

4. Spin — press Spin. The server settles the round against your real balance.

Bet types & payouts

  • Straight (single number) — pays 35:1 (36× stake returned)
  • Dozen (1st/2nd/3rd 12) — pays 2:1
  • Column (2 TO 1) — pays 2:1
  • Red / Black, Even / Odd, 1–18 / 19–36 — pays 1:1
  • 0 — only straight bets on 0 win; even-money bets lose

Info

Roulette — European single-zero wheel (0–36).

Results are decided by the server. Your Gundu wallet balance is used for all bets — there is no demo mode.

Minimum chip: ₹10. Place at least one bet before spinning.
