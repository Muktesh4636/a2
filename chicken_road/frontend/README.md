# Chicken Road — Frontend

React + Vite + Pixi.js game UI.

## Setup

```bash
cd frontend
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start Vite dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run oxlint |

## Backend

Game API lives in `../backend`. Start it separately on port `8000` when wiring live play.
